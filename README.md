# ⚡ get-openfonts CLI
> Command-line tool to instantly search, download, and install over **80,000+ curated open-source typefaces** across Bengali, English, Arabic, Hindi, and German.

Curated and maintained by **[Mohammad Golamrabbii](https://linktr.ee/golamrabbii)**.  
Live Web Previewer: **[mohammadgolamrabbii.github.io/typography](https://mohammadgolamrabbii.github.io/typography/)**

---

## 🚀 Quick Usage (No Installation Needed via NPX)

### 1. List All Available Collections
```bash
npx get-openfonts list
```

### 2. Download Official Release ZIP (1-Click)
```bash
npx get-openfonts download bangla
npx get-openfonts download english
npx get-openfonts download arabic
npx get-openfonts download hindi
npx get-openfonts download german
```

### 3. Shallow Clone Any Mega Archive
```bash
npx get-openfonts clone english
```
